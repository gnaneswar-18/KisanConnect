# KisanConnect
### Connecting Farmers and Merchants Digitally

## Overview
**KisanConnect** is a full-stack web application that enables direct interaction between **farmers and merchants**.  
It helps farmers list crops and share knowledge, while merchants can discover agricultural products based on **location and category**.

The platform reduces middlemen and promotes transparent agricultural trade.


## Features

### Farmers
- Crop listing and management
- Knowledge sharing
- Community interaction
- Direct chat with merchants

### Merchants
- Location-based crop search
- Discover farmers
- Real-time communication
- Price comparison

### Platform
- Smart search and filters
- Real-time chat (Socket.io)
- JWT authentication
- Responsive design

---

## Tech Stack
- **Frontend:** React (Vite), Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Real-time:** Socket.io
